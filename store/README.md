## 스크린샷 6장

SPEC.md 17.1 의 목록이다. 앱에 아래 상태를 만들어 두고 한 장씩 찍는다.

| 순서 | 화면 | 만들어 둘 상태 | 보여 줄 것 |
| --- | --- | --- | --- |
| 1 | 오늘 탭 | 밀린 식물 1, 오늘 줄 식물 1, 다가옴 1, 오늘 준 식물 1 | 큰 날짜와 계절 이름표, 개수 칩, 물 줬어요 |
| 2 | 공간 상세 | 창가 공간에 사진과 밝기 | 사진으로 가늠한 이 자리의 빛과 근거 |
| 3 | 식물 상세 | 사진 두 장 이상인 식물 | 다음 물주기 큰 날짜, 남은 날, 관리 카드 |
| 4 | 식물 상세 (분재) | 이번 달 작업이 있는 분재 | 흙 확인 알림과 작업 달력 |
| 5 | 오늘 탭 (경고) | 한파나 서리 예보가 있는 날 | 날씨 경고 카드와 날씨 아이콘 |
| 6 | 기록 탭 | 물 준 기록 여러 날 | 날짜별 타임라인과 식물별 평균 |

4번과 5번은 그냥은 안 나온다. 분재 작업은 종 DB 에 `bonsai_tasks` 가 있는 수종을 등록하면
`plant_tasks` 로 복사되고, 날씨 경고는 지역을 고른 뒤 한파·서리가 예보된 날에 뜬다.
테스트용으로 기기 DB 에 값을 넣어 찍었다면 찍고 나서 반드시 되돌린다.

## 크기

| 스토어 | 필요한 것 |
| --- | --- |
| 앱스토어 | 6.9인치 1320×2868 (또는 1290×2796). 6.5인치는 1284×2778 |
| 플레이스토어 | 폰 16:9~9:16 사이, 짧은 변 1080px 이상. 2~8장 |

`shot.sh` 가 찍은 원본과 6.9인치로 맞춘 파일을 함께 만든다. 다만 제출용은
6.9인치 시뮬레이터에서 직접 찍는 것이 가장 깨끗하다.

## 찍기 전에

1. **개발 빌드로 켠다.** Expo Go 에서는 오른쪽 아래 파란 개발용 버튼이 함께 찍힌다
   (Expo Go 의 Tools button 을 꺼도 화면에 남는 경우가 있다).
2. 상태 표시줄을 깨끗하게 한다.

   ```bash
   xcrun simctl status_bar booted override --time "9:41" \
     --batteryState charged --batteryLevel 100 --cellularBars 4 --wifiBars 3
   ```

3. 라이트 모드로 찍는다. 다크 모드 한 장을 곁들이려면 마지막에 넣는다.
4. 다 찍으면 되돌린다.

   ```bash
   xcrun simctl status_bar booted clear
   ```
